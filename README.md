## 🌟 핵심 기능 (Key Features)

- **브랜드별 원클릭 필터 탭**: 8대 브랜드별 대표 링 즉시 선택 및 정가 자동 입력
- **1인 vs 2인 커플 모드 지원**: 1인 단독($800 면세) 또는 2인 커플링($1,600 면세 & 감면 40만원)
- **정밀한 일본 실구매가 산출**:
  - 브랜드별 백화점 게스트카드 5% 할인 적용 규칙 (샤넬/까르띠에 불가, 쇼메/타사키 적용 등)
  - Tax Free 환급 (백화점 8.45% vs 부티크 10.0%)
  - 결제 수수료 (트래블카드 0% vs 일반 카드 1.5%)
  - 세관 $800 면세 초과분 관부가세(18.8%) 및 자진신고 30% 감면 (최대 20만 원)
- **한국 백화점 실구매가 비교**: 상품권 할인 결제(3.0%) 및 웨딩 마일리지 클럽
- **실시간 환율 연동**: JPY/KRW, USD/KRW, USD/JPY 자동 조회 및 수동 조정
- **비주얼 판정 & 여행 혜택 지수**: 절약 금액으로 항공권/호텔 세이브 여부 가이드
- **공식몰 크롤링 검증 모달**: 전체 모델의 한국/일본 공식몰 검증 상태 실시간 확인
- **자동 데이터 갱신 파이프라인**: GitHub Actions 스케줄러를 통한 주간 자동 검증
